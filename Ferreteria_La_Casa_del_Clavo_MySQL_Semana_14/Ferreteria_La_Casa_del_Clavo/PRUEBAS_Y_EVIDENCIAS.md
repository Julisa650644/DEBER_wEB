# Registro de pruebas y evidencias

Complete esta hoja después de ejecutar MySQL y Flask. Inserte sus capturas en
los espacios indicados antes de entregar.

| Prueba | Resultado esperado | Evidencia que debe insertar |
|---|---|---|
| Conexión Flask–MySQL | La página inicia sin error | Inicio y MySQL Workbench activo |
| SELECT | Productos aparecen en la tabla | Listado de Productos |
| INSERT | El nuevo producto aparece inmediatamente | Formulario, alerta verde y SELECT en Workbench |
| UPDATE con WHERE | Solo cambia el producto elegido | Formulario editado y SELECT posterior |
| DELETE con WHERE | Solo desaparece el producto elegido | Confirmación, listado y SELECT posterior |
| JOIN | Se muestra el nombre del proveedor | Columna Proveedor del listado |
| Persistencia | Los cambios continúan al reiniciar Flask | Listado después de reiniciar |
